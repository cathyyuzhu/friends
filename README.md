# friends

虚拟朋友群聊 —— 几个有独立人设、共享记忆的 AI 朋友，在群里像真实朋友一样跟你聊天、互相接话、主动分享新鲜事。

## 现状：终端 MVP

当前版本是一个终端里的最小可用版本，用来验证"人设 + 共享记忆 + 是否接话的调度"这个核心机制是否好玩，还没接 Telegram。

三个默认人设（`personas.json`）：
- 📚 阿哲 —— 书、小说、电影
- 🎧 小鹿 —— 音乐、演唱会
- 🎨 林川 —— 哲学、绘画

## 运行

```bash
pip install -r requirements.txt
cp .env.example .env   # 填入你的 ANTHROPIC_API_KEY
python main.py
```

命令：
- 直接打字：在群里发消息，AI 朋友会根据话题和各自的"话痨程度"决定要不要接话、谁接话
- `/tick`：不发消息，让某个朋友自己主动冒泡分享点新鲜事（模拟"朋友自己想到什么就说了"）
- `/who`：看看都有谁
- `/history`：看最近的聊天记录
- `/reset`：清空记忆重新开始
- `/quit`：退出

聊天记录会存在 `data/chat_log.json`（不进 git），下次运行会接着读取，所以朋友们"记得"之前聊过什么。

## 已知的简化 / 下一步

- 调度是否接话用的是关键词 + 随机权重的简单启发式，不是真正的"人格化决策"，后续可以换成更聪明的判断
- 目前没有做"每周聚会""约看电影/读书"这类主动发起的活动，先验证日常闲聊的效果
- 还没接 Telegram：等终端版的人设和互动感觉对了，再把调度逻辑搬到 Telegram bot 上，每个朋友一个独立 bot 身份
