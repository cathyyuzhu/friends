# friends

虚拟朋友群聊 —— 几个有独立人设、共享记忆的 AI 朋友，在群里像真实朋友一样跟你聊天、互相接话、主动分享新鲜事。

三个默认人设（`personas.json`）：
- 🧠 阿哲 —— 哲学
- 🎧 音 —— 音乐、美术
- 📚 舒舒 —— 读书、看电影

共享的调度核心在 `chat_engine.py`：谁接话、要不要接话、主动冒泡分享——终端版和 Telegram 版用的是同一套逻辑，只是"输入输出"不一样。

## 版本一：终端 MVP（`main.py`）

用来最快验证"人设 + 共享记忆 + 调度"这个核心机制好不好玩，只在本地终端跑，不需要任何聊天平台。

```bash
pip install -r requirements.txt
cp .env.example .env   # 填入你的 ANTHROPIC_API_KEY
python main.py
```

命令：
- 直接打字：在群里发消息，AI 朋友会根据话题和各自的"话痨程度"决定要不要接话、谁接话
- `/tick`：不发消息，让某个朋友自己主动冒泡分享点新鲜事（模拟"朋友自己想到什么就说了"）
- `/who`：看看都有谁
- `/history`：看最近的聊天记录
- `/reset`：清空记忆重新开始
- `/quit`：退出

## 版本二：Telegram 群（`telegram_bot.py`）

同一套调度逻辑，接到真实的 Telegram 群里，每个朋友是一个独立的 bot 身份（有自己的名字、头像），在群里跟你聊天。

> **国内用户注意**：Telegram 在中国大陆被墙，本机需要能科学上网访问 `api.telegram.org` 才能用这个版本，否则会连接失败。

准备步骤（一次性）：
1. 找 [@BotFather](https://t.me/BotFather)，对 `personas.json` 里每个人设执行 `/newbot`，拿到 token（可以顺便用 `/setuserpic` `/setdescription` 给每个 bot 设置头像和简介，更有"人味"）
2. 对用作监听者的那个 bot（默认是第一个人设）执行 `/setprivacy` → Disable，这样它才能看到群里所有人的消息，不只是 @它 的消息
3. 建一个 Telegram 群，把所有 bot 都拉进去
4. 把 token 填进 `.env`（变量名 `TG_TOKEN_<人设ID大写>`，见 `.env.example`）

运行：

```bash
python telegram_bot.py
```

第一次运行不用填 `TG_GROUP_CHAT_ID`：在群里发条消息，终端会打印检测到的 chat_id，填进 `.env` 后重启，之后就只监听这一个群。运行起来后正常在群里聊天即可；发 `/tick` 可以立即测试"主动冒泡"效果，不用等后台定时器（默认 90~240 分钟随机触发一次，可以在 `.env` 里调小方便测试）。

这个脚本需要一直跑着才有效果，关掉终端/进程就停了——先在自己电脑上跑着玩，等感觉对了再考虑部署到一台常开的机器（云主机、树莓派之类）上，让朋友们真正"一直在线"。

## 已知的简化 / 下一步

- 调度是否接话用的是关键词 + 随机权重的简单启发式，不是真正的"人格化决策"，后续可以换成更聪明的判断
- 目前没有做"每周聚会""约看电影/读书"这类主动发起的活动，先验证日常闲聊的效果
- Telegram 版目前一次只服务一个群（一份共享的 `data/chat_log.json`），没做多群隔离
- 还没做持久化部署，进程停了朋友们就"下线"了
